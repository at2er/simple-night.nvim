1. Configuartion		*simple-night.nvim-configuartion*

Additional settings for simple-night are:
>lua
  -- Default options:
  require("simple-night").setup({
    transparent = false,
    styles = {
      comments = { italic = true },
      keywords = { bold = false },
    },
    plugins = {
      "cmp",
      "ibl",
      "neotree",
      "treesitter",
      "lsp",
    },
  })
<
